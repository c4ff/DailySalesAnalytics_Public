# Holy Cow Sales Analytics Dashboard

## Overview

Sales analytics project analyzing daily restaurant transaction data. The project demonstrates a complete analytics workflow including data cleaning and database development using Python; SQL analysis, and PowerBI dashboard visualization.

## Project Workflow

1. Data Cleaning
   - Cleaned raw transaction data using Python
   - Standardized date fields and numerical values
   - Removed inconsistencies and unused columns before analysis

2. Database Development
   - Loaded processed data into SQLite database
   - Created analytical tables for querying

3. SQL Analysis
   - Developed SQL queries to analyze:
     - Sales performance
     - Order trends
     - Daily and monthly patterns
     - Revenue breakdowns

4. Dashboard Development
   - Built Power BI dashboard to visualize:
     - Total sales KPIs
     - Monthly sales trends
     - Sales performance by weekday
     - Top-performing periods

## Tools Used

- Python (Pandas)
- SQL (SQLite)
- Power BI
- Git/GitHub
